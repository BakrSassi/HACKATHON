# ✨ AURA - Votre Gardien Financier Intelligent

![AURA](https://img.shields.io/badge/Version-1.0-blue) ![React](https://img.shields.io/badge/React-19.2-61dafb) ![License](https://img.shields.io/badge/License-MIT-green)

## 💡 Concept Global

**AURA** est un site web intelligent de gestion de patrimoine qui agit comme une **aura numérique de protection** autour des investissements de l'utilisateur.

Ce n'est pas juste un tableau de bord financier, mais un **écosystème de confiance** où chaque donnée, chaque décision et chaque transaction est :
- ✅ **Analysée par IA**
- ✅ **Vérifiée par Blockchain**
- ✅ **Sécurisée proactivement** par des mécanismes de cybersécurité intégrés

### 🎯 Objectif
> "Rassurer, guider et protéger les investisseurs dans un monde financier incertain."

---

## 🚀 Modules Principaux

### 1. 🧠 SmartBrain (IA & Machine Learning)
- Analyse tous les actifs : actions, cryptos, fonds, obligations
- Calcule une **Note d'Aura (0-100)**
- Génère des recommandations personnalisées
- Apprentissage continu

### 2. 🛡️ CyberGuardian (Cybersécurité Proactive)
- Scan en temps réel
- Détection de phishing
- Analyse des vulnérabilités
- Blocage automatique des menaces

### 3. ⛓️ TrustLedger (Blockchain)
- Enregistrement immuable
- Signature cryptographique
- Historique vérifiable
- Traçabilité totale

### 4. 💬 AURA Chat (Assistant IA)
- Interface conversationnelle
- Explications détaillées
- Contexte personnalisé
